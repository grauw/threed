Project information
-------------------

3D rendering engine

Author: Laurens Holst <laurens.nospam@grauw.nl>  
Site: <https://bitbucket.org/grauw/threed>  

Coordinate system is left-handed, with positive x pointing right, positive y
pointing up and positive z pointing forward.


System Requirements
-------------------

  * MSX turboR
  * 128kB video RAM
  * 64kB main RAM
  * 64kB Konami 4/5 ROM
